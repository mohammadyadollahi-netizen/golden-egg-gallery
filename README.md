````markdown
# 🥚 Golden-Egg

### Digital Art NFT Collection

Golden-Egg is a digital art NFT collection built with **ERC-721**, **Ethereum Sepolia Testnet**, and **IPFS-based metadata**.

The project focuses on creating, documenting, and showcasing blockchain-based digital artworks through a simple and transparent collection structure.

# 📦 IPFS

Golden-Egg uses IPFS to store NFT metadata and artwork references.

The NFT metadata follows the standard `ipfs://` URI format.

Example:

```text
ipfs://bafkreihytiwjjsw4nr3dvgh5dyyzxw3qqs6jrbmomhxdioxrbhtblgw4t4
````

The image referenced by Golden-Egg #2 uses:

```text
ipfs://bafybeihra6q5yvnyitntkpt3gd5eynkuzjhmsqfsvcbmuopvapmyqz6dku
```

