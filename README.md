## ✨ About

Golden-Egg is a digital art NFT collection built with:

- ERC-721
- Ethereum Sepolia Testnet
- IPFS metadata
- GitHub Pages
- On-chain ownership and token URI verification

The initial collection is planned as **3 artworks**.
