# 🥚 Golden-Egg

### A Digital Art Collection on Ethereum Sepolia

Golden-Egg is an experimental digital art collection built using the **ERC-721 NFT standard**. The project explores NFT creation, decentralized media storage with IPFS, blockchain ownership, metadata, and on-chain verification.

> **Network:** Ethereum Sepolia Testnet
> **Token Standard:** ERC-721
> **Collection Symbol:** GEGG
> **Minted NFTs:** 3

---

## ✨ Project Overview

The Golden-Egg project combines digital artwork with blockchain-based token records and IPFS-hosted assets.

* **Digital Art:** Three individual artworks in the collection.
* **NFT Standard:** ERC-721.
* **Decentralized Storage:** IPFS image and metadata references.
* **Blockchain Records:** Token ownership and contract information.
* **Gallery Website:** A web interface for viewing the collection.
* **On-chain Verification:** Checks for contract and token information.

## 🚀 Run the Gallery Locally

1. Clone or download this repository.
2. Open `index.html` in a modern browser.
3. Use the Gallery and About links to explore the project.
4. Open the Etherscan links to inspect the token records.

Some browser-based verification features require an internet connection to reach the Sepolia RPC and supporting JavaScript libraries.

## 🔍 Verification

You can independently inspect the contract and token records using the Etherscan links above. The gallery's live verification indicators depend on external RPC and gateway services, so temporary network failures may affect the displayed status without changing the blockchain records.
