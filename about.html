About Golden-Egg

Golden-Egg is a digital art collection created to explore NFT technology, blockchain ownership, ERC-721 smart contracts and decentralized metadata using IPFS.

4 / 4 Minted Artworks · Collection Complete

Project Overview

Golden-Egg combines digital artwork with blockchain technology. Each artwork is represented by an ERC-721 NFT on the Ethereum Sepolia Testnet.

The project is designed as a practical exploration of how digital artwork, NFT metadata, IPFS and blockchain records can work together.

Blockchain

The collection uses an ERC-721 smart contract deployed on the Ethereum Sepolia Testnet.

IPFS

Artwork files and NFT metadata are referenced through IPFS content identifiers (CIDs).

NFT Standard

Each Golden-Egg artwork is represented using the ERC-721 non-fungible token standard.

How Golden-Egg Works

  1. A digital artwork is created for the collection.
  2. The artwork is stored using IPFS.
  3. NFT metadata is created and stored using IPFS.
  4. The metadata URI is associated with an ERC-721 token.
  5. The token is recorded on the Ethereum Sepolia blockchain.
  6. The blockchain transaction, token and metadata references can then be independently inspected.

The Collection

The current Golden-Egg collection contains four minted artworks. Each token has its own artwork, metadata and blockchain transaction.
