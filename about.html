About Golden-Egg

Golden-Egg is an experimental digital art collection built around the ERC-721 NFT standard, Ethereum blockchain technology, and decentralized IPFS storage.

Collection Complete · 4 / 4 Minted

The Project

Golden-Egg is a digital art project created to explore the technical and creative foundations of NFTs.

Each artwork is represented as an ERC-721 token and connected to its metadata through an IPFS content identifier (CID).

The collection currently contains four minted artworks, identified as Token #1 through Token #4.

Technology

The project combines several technologies to create a transparent and verifiable NFT structure.

IPFS Storage

Artwork files and NFT metadata are referenced through IPFS. This separates the digital assets from the blockchain while keeping their content-addressed identifiers available for verification.

Each Golden-Egg token has its own image CID and metadata CID.

The Collection

The current collection consists of four individual artworks. Each token has its own dedicated page containing blockchain, metadata, IPFS and transaction information.

How Golden-Egg Works

1

Artwork

A digital artwork is prepared for the collection.

2

IPFS

The artwork and its metadata are stored using IPFS content identifiers.

3

Token

The metadata URI is associated with an ERC-721 token on the Ethereum Sepolia testnet.

4

Verification

The token, owner, transaction and metadata can be independently inspected using blockchain and IPFS references.

Testnet Notice

Golden-Egg is currently deployed on the Ethereum Sepolia Testnet for development, experimentation and learning.

These tokens are testnet assets and should not be considered Ethereum Mainnet assets or an indication of market value.
