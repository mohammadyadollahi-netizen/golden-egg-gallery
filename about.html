About Golden-Egg

Golden-Egg is a small experimental digital-art project created to explore the complete lifecycle of an NFT: artwork creation, decentralized storage, smart contracts, minting, blockchain verification, and web presentation.

The Project

Golden-Egg is a focused experiment in creating, storing, minting, and presenting digital art on a public blockchain.

The collection uses the ERC-721 standard and is currently deployed on the Ethereum Sepolia Testnet. Each artwork has an individual Token ID and an on-chain Token URI pointing toward decentralized metadata.

The project is designed as both a digital-art showcase and a practical learning project for understanding how NFTs connect artwork, metadata, IPFS, smart contracts, blockchain transactions, and a public website.

How Golden-Egg Works

01

Artwork

Digital artwork is prepared for the Golden-Egg collection.

02

IPFS

Artwork files and NFT metadata are stored using IPFS.

03

Smart Contract

The ERC-721 smart contract defines the collection and NFT ownership structure.

04

Minting

Each artwork receives its own Token ID and blockchain record.

05

Verification

Ownership and Token URI records can be checked directly on Ethereum Sepolia.

06

Gallery

The public website presents the artwork and connects it to its blockchain records.

Technology

Ethereum Blockchain ecosystem used for the NFT records.
ERC-721 Standard used for the Golden-Egg NFT collection.
IPFS Decentralized content-addressed storage for artwork and NFT metadata.
GitHub Pages Public web hosting for the Golden-Egg gallery.
Sepolia Ethereum test network used during development and experimentation.
Blockchain Records Token ownership, minting transactions, and Token URI records are documented alongside the collection.
