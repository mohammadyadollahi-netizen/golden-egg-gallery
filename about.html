Golden-Egg

A digital art collection built on Ethereum Sepolia using the ERC-721 NFT standard.

Ethereum Sepolia · ERC-721 · GEGG

About the Project

Golden-Egg is a digital art collection created to explore the process of building, storing, minting and verifying NFTs on a blockchain network.


The collection currently contains three ERC-721 NFTs. Each artwork has its own image and metadata stored through IPFS, while ownership and token information are recorded on the Ethereum Sepolia blockchain.

Project Structure

🎨 Digital Art

Each Golden-Egg NFT represents an individual digital artwork with its own token ID and metadata.

⛓️ Blockchain

The collection uses the ERC-721 standard on Ethereum Sepolia.

📦 IPFS

Artwork images and NFT metadata are referenced through IPFS content identifiers.

🔎 Verification

Token ownership, metadata and contract information can be independently checked through the blockchain explorer.

IPFS & Metadata

Golden-Egg artwork files and metadata are referenced using IPFS content identifiers. This separates the digital artwork data from the blockchain while allowing the NFT metadata to point to the corresponding artwork.
