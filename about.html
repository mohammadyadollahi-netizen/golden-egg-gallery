About Golden-Egg

The idea behind the collection is to combine digital artwork with transparent blockchain ownership and decentralized metadata.

Golden-Egg is currently a three-piece initial collection. The first two artworks have been minted on Ethereum Sepolia, with artwork references and metadata stored through IPFS. A third artwork is planned for a future release.

Technology

Golden-Egg combines blockchain infrastructure with decentralized metadata and a public project gallery.

ERC-721

The collection uses the ERC-721 NFT standard for unique token identification and ownership.

Ethereum Sepolia

The current contract is deployed on the Sepolia Testnet for development, testing, and verification.

IPFS

Artwork and metadata references use IPFS content identifiers and ipfs:// token URI references.

GitHub Pages

The public Gallery is hosted through GitHub Pages and provides an accessible presentation layer for the collection.

Smart Contract

The collection is associated with a verified ERC-721 contract on Ethereum Sepolia.

Roadmap

Current development path for the initial Golden-Egg collection.

COMPLETED

Create the Golden-Egg collection, deploy the ERC-721 contract, mint #1 and #2, store metadata on IPFS, and publish the Gallery and documentation.

NEXT

FUTURE

Review the completed collection and evaluate production deployment and marketplace compatibility.
